================================================================================
  AUTHENTICATION FLOW: ✅ WORKING
================================================================================

Login Process:
  1. User clicks "Login" button
  2. generateOAuthURL() creates OAuth URL with PKCE & CSRF
  3. User redirected to Deriv login (auth.deriv.com/oauth2/auth)
  4. User enters credentials and grants permission
  5. Deriv redirects back with authorization code
  6. App validates CSRF token (security)
  7. App exchanges code for access token using PKCE
  8. App fetches user accounts
  9. App initializes WebSocket connection
  10. User logged in and redirected to dashboard
